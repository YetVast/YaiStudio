# Reference Documents

The reference files in this directory were supplied by the product owner. They are included to ground implementation in current YVS and YAI decisions. Read the YAI architecture source, Cogmit storage reference, current Yet Vast Auth documentation/handbook, private package standard and YVS engineering standards before implementation.

Do not treat an illustrative example as implemented behavior. Do not transfer Cogmit-specific domain semantics to YAI. The current Auth SDK package and central registration remain authoritative for actual runtime integration.
